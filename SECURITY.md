# Security policy

## Supported versions

Security fixes are made for the latest release. Please update before reporting.

## Reporting a vulnerability

Please report security or privacy problems **privately** through
[GitHub's private vulnerability reporting](https://github.com/lobojoel2003/Blurlist/security/advisories/new)
rather than in a public issue. Include the version and build number from **Settings → About**, your operating
system and steps to reproduce.

**Do not include real photos of children or of anyone on a roster.** If an image is needed to reproduce the
problem, use a photo of yourself, a public-domain image or a synthetic one.

You can expect an acknowledgement within a week. Examples of what we especially want to hear about:

- a face that should be blurred being exported unblurred while Blurlist reports success;
- metadata (GPS, camera, embedded thumbnails) surviving export;
- any network traffic from the app;
- data from one event or roster leaking into another.
